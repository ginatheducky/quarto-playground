Welcome to my _new blog_ about learning Astro! Here, I will share my learning journey as I build a new website.

1. **Installing Astro**: First, I created a new Astro project and set up my online accounts.

This is a test.

The first test was fairly simple. I found [instructions from glenn-de-backer](https://github.com/glenn-de-backer/pico-switch-controller) on github on how to wire 4 buttons to the pico to test the setup. It was really easy and simple following his instructions and after 30 minutes, I had a very rough setup with jumper wires and some button that could drive a car in Mario Cart on the Switch.

open source projects already available. Luckily for me, there are. I found the [GP2040-CE](https://gp2040-ce.info/) project, which sounded very promising.

> ::: {.quote-box}
> GP2040-CE (Community Edition) is a gamepad firmware for the Raspberry Pi Pico and other boards based on the RP2040 microcontrollers that combines multi-platform compatibility, low latency and a rich feature set to provide endless customization possibilities without sacrificing performance.
:::

And it supports the Nintendo Switch.
